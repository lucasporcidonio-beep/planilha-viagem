💾 Backup e Gerenciamento de Dados

Todos os seus dados estão salvos com segurança no navegador. Faça backup para não perder nada:

☁️ Ativar Sincronização na Nuvem (Firebase)

⚠️
Regras de Segurança Bloqueadas

O Firebase está conectado, mas o Google bloqueia leitura e gravação até você liberar as regras no painel. Sem isso, os dados não salvam em outros dispositivos.

Passo a passo rápido (30 segundos):

  1. 1. Abra a aba de Regras do seu projeto Firebase:
    🔗 Abrir Regras do Firestore no Firebase Console ↗
  2. 2. Substitua o texto que está na aba Rules por este: 
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
  3. 3. Clique no botão azul "Publicar" (Publish) no Firebase Console.

💡 Assim que você clicar em Publicar, o indicador no topo ficará verde ("Nuvem Conectada") e todas as suas viagens e lojas serão sincronizadas automaticamente entre o celular e o computador!
